# Timber Wolf

The Clan Wolf OmniMech the Inner Sphere calls the *Mad Cat*. First encountered
during Operation Revival, and still the machine most people picture when they
hear the word BattleMech.

Everything below is from Sarna and nothing has been rounded, averaged or filled
in. **A field nobody sourced is absent from this file**, and the scanner draws
only the blocks it has data for — so the honest failure mode of an incomplete
canon.md is a shorter readout, never a confident wrong one.

Note in particular what is *not* here: Sarna lists the Prime's nine weapons but
assigns none of them to a body location, so neither does this file. An earlier
version of this program put the ER larges "in the arms" and the LRM-20s "in the
side torsos" — the sort of thing everyone knows and nobody sourced.

## Notes

- The codename came from Phelan Kell's Wolfhound targeting computer, which
  switched between MAD and CAT while trying to identify it; Focht later made
  the designation official.
- No quirk field: Weak Head Armor is a tabletop rules modifier, not something
  true about the machine in the fiction, and the panel is a lore readout.
